# 導入の手引き

自院で使うために書き換えるところを、作業の順に並べます。

## 1. 当直の枠を決める

`data/frames.json` が枠マスタです。
1つの枠は「科 × 役割（ファースト・セカンド以下）× 昼／夜」で、定員（当直・オンコール）と、どの提出単位（owner）が入力するかを持ちます。
見本の枠が入っています。
自院の当直表に合わせて作り直してください。

- `data/dept_map.json`: 提出単位ごとに、どの所属の医師を名簿に出すか。
- `data/holidays.csv`: 祝日・年末年始・開院記念日など（休診だが昼は全員オンコールにする日は `daytime_oncall_only` を 1 にする）。土日祝の判定はセルの色ではなく、この表で行います。
- `data/toban.csv`: 日ごとの当番科（使わなければ空でかまいません）。

## 2. 置き場を決める

`tools/contract.py` の `PROD_ROOT` が共有フォルダの場所です（見本は `\\fileserver\share$\00_DrJOY\当直勤務表`）。
月ごとに `R8年N月\` のようなフォルダができ、その中にアプリ・設定（config）・予定表（master）が入ります。
月のフォルダは `tools/month_setup.py` が作ります。

ほかに場所を持っているファイル:

| ファイル | 持っているもの |
|---|---|
| `tools/dtx14_daily_sync.py` | 当直表（Excel）の正本がある SharePoint の同期フォルダ（`SYNC_ROOT`）・警報の宛先 |
| `tools/shozoku_notice.py` | 所属の変更を知らせるメールの宛先 |
| `drjoy_import/tools/*.py` | 共有フォルダの場所（`DUTY_ROOT`） |
| `drjoy/tasks/*.ps1` | タスク スケジューラで動かすときの宛先と場所 |

メールアドレスは `userNNN@example.ac.jp` という見本の値になっています。

## 3. 名簿を用意する

名簿は Dr.JOY のスタッフ一覧の CSV です（`drjoy/drjoy-staff-export.js` で書き出せます）。
`tools/make_staff_csv.py`・`tools/roster_refresh.py` が、アプリの使う形に直して共有フォルダへ置きます。
人を突き合わせる鍵は Dr.JOY のログインIDです。
氏名は表示にだけ使います（同姓同名と異体字の事故を避けるため）。

## 4. アプリを作る

```
cd app
npm install
npx electron-builder --win
```

できた `app/release/*.exe` を月のフォルダへ置きます（`tools/deploy_prod.py`）。
起動を速くしたいときは `tools/build_launcher.bat` で起動係と zip を作ります。

## 5. 月の流れ

1. `MonthlySetup.bat`（または管理ツールの①）で、その月のフォルダと設定を作る。
2. 各科がアプリで入力して保存する。
3. 管理ツールの②で提出状況を確かめる。
4. 決裁が済んだら、管理ツールの③で「この月を確定」する。以後の変更は交代申請として記録される。
5. 毎日決まった時刻に `tools/dtx14_daily_sync.py` を動かし、当直表の Excel と PDF を作り直す。

## 6. Dr.JOY へ入れる

1. `drjoy/` で `npm install` し、`node drjoy-staff-export.js` を一度ふつうに起動して Dr.JOY にログインする（専用の Chrome のプロファイルにログインが残ります）。
2. `drjoy_import/build_sep_import.py` で、当直表から Dr.JOY の勤務予定の取り込み用 xlsx を作る。
3. `node drjoy/drjoy-at0069-import.js --file <xlsx>` で取り込む。

⚠ 手当を計算している月に勤務予定を入れ直すと、その日の時間外の申請が消えることがあります。
入れるのは翌月分だけにしてください。

## 7. 当直表の Excel について

`tools/dtx14_*.py` は、この病院で長く使ってきた当直表の Excel（マクロ付き）に書き込むためのものです。
自院の当直表の形が違うときは、`tools/duty_sheet.py` が作る月間カレンダー形式の当直表だけを使い、`dtx14_*` は使わずにおくのが近道です。
